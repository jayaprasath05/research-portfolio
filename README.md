# Research Portfolio (Internship Project)

A Figma design file created during my internship.

## About

This repository holds the Figma source file (`Research_Portfolio.fig`), a project I designed as part of my internship. It includes the layout, visuals, and content created for this project.

## File

- `Research_Portfolio.fig` — Original Figma project file. Open it with [Figma](https://www.figma.com) to view or edit.

## How to open

1. Download `Research_Portfolio.fig` from this repository.
2. Go to [figma.com](https://www.figma.com) and log in (or create a free account).
3. Click **Import** and select the downloaded `.fig` file.
