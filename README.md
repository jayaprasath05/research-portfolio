- **Organization:** Codtech IT Solutions Private Limited
- **Role:** UI/UX Design Intern

This repository holds the Figma source file (`Research_Portfolio.fig`) along with page preview screenshots, designed for **ScholarTrust AI** — a concept research portfolio website featuring a homepage, project deep-dives, publications repository, about page, and contact page.

## Files

- `design/` — PNG previews of each page in the design.

## How to open the Figma file

1. Download `Research_Portfolio.fig` from this repository.
2. Go to [figma.com](https://www.figma.com) and log in (or create a free account).
3. Click **Import** and select the downloaded `.fig` file.
